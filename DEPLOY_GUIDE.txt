GitHubへの更新・プッシュ手順まとめ

更新作業が終わったら、以下の手順でGitHubに変更を送信してください。
Vercelと連携済みの場合、Pushするだけで自動的に本番環境も更新されます。

---

【基本の3ステップ】
ターミナル（コマンドプロンプト）で実行します。

1. 変更ファイルをすべて選択
   git add .

2. 変更を保存（メッセージは変更内容に合わせて変えてください）
   git commit -m "機能追加とスマホ対応"

3. GitHubへ送信
   git push

---

【エラーが出る場合】
もし "git pull" を求められた場合は、先に以下のコマンドを実行して、GitHub上の最新情報を手元に取り込んでください。
   git pull

---

【Vercelのデプロイ確認】
Push完了後、Vercelのダッシュボードを見ると "Building" になり、数分で新しいバージョンが公開されます。
