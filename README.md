# MochiList

カラオケ・弾き語りリスト管理アプリケーション

## 概要
MochiListは、持ち歌のキーや音域情報を管理し、選曲をサポートするWebアプリケーションです。

## 動作環境
- Node.js (v16以上推奨)
- npm

## セットアップ
初回のみ以下のコマンドで依存関係をインストールしてください。

```bash
npm install
```

## 起動方法 (開発モード)
以下のコマンドでローカルサーバーを起動します。

```bash
npm run dev
```

起動後、ターミナルに表示されるURL（通常は `http://localhost:5173`）をブラウザで開いてください。

## ビルド (本番用)
静的ファイルとして出力する場合：

```bash
npm run build
```
`dist` フォルダに生成されます。
